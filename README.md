# cctv-monitor

🛰️ **CCTV Monitor - Multi-View NVR Station (Grid 3x3)**

Aplikasi software CCTV NVR live monitoring untuk kamera CCTV (AliOS Things / AltoBeam / RTSP IP Camera) di jaringan lokal.

### Fitur Utama:
- **Tampilan Grid 3x3 Matrix:** Fullscreen edge-to-edge view dengan zero scrollbar.
- **Multi-Quality Streaming:** Pengaturan resolusi (360p, 480p, 720p HD, 1080p FHD) hemat bandwidth.
- **RTSP / HTTP Live Stream:** Terhubung langsung ke feed kamera jaringan lokal.
- **Web-based Interface:** Dashboard modern dan responsif.

### Menjalankan Aplikasi:
- **Linux:** `./start_server.sh`
- **Windows:** Jalankan `JALANKAN_CCTV_MONITOR.bat`
- Akses melalui browser: `http://localhost:5000`
