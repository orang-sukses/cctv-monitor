========================================================================
  🛰️  CCTV MONITOR - MULTI-VIEW NVR STATION (GRID 3x3) 🛰️
========================================================================

Aplikasi ini adalah software CCTV NVR live monitoring khusus untuk 7 kamera
AliOS Things (AltoBeam CCTV) di jaringan WiFi Anda.

Fitur Unggulan:
1. YouTube-Style Quality Settings (Default 360p, 480p, 720p HD, 1080p FHD):
   Streaming hemat bandwidth dan sangat ringan, menjaga internet WiFi Anda
   tetap cepat dan lancar.
2. Tampilan Software NVR 3x3 Matrix:
   Tampilan layar penuh tepi-ke-tepi (edge-to-edge), auto-hide navbar atas,
   dan zero scrollbar.
3. Live RTSP Streaming:
   Mengambil feed video langsung dari chip kamera:
   - CH-01: 192.168.1.4  (Ruang Utama)
   - CH-02: 192.168.1.5  (Pintu Masuk)
   - CH-03: 192.168.1.6  (Halaman Depan)
   - CH-04: 192.168.1.7  (Koridor Samping)
   - CH-05: 192.168.1.16 (Kamera 16)
   - CH-06: 192.168.1.20 (Kamera 20)
   - CH-07: 192.168.1.13 (Kamera 13)
4. Kecepatan Internet CCTV Real-Time:
   Speedometer kecepatan internet pemakaian CCTV langsung di navbar atas.

------------------------------------------------------------------------
 CARA MENJALANKAN DI WINDOWS (DI LUAR WSL):
------------------------------------------------------------------------
1. Buka folder "CCTV-Monitor" di Desktop Windows Anda:
   C:\Users\ahmad\Desktop\CCTV-Monitor
2. Klik 2x pada file:
   👉 JALANKAN_CCTV_MONITOR.bat
3. Buka browser ke:
   👉 http://localhost:8080

------------------------------------------------------------------------
 CARA MENJALANKAN DI WSL / LINUX:
------------------------------------------------------------------------
1. Buka terminal di folder: /home/ahmad/cctv-monitor (atau /home/ahmad/zte-wifi-scanner)
2. Jalankan perintah:
   👉 ./start_server.sh
3. Buka browser: http://localhost:8080

------------------------------------------------------------------------
 PANDUAN PINTAS (KEYBOARD SHORTCUTS):
------------------------------------------------------------------------
- Tombol 1 s/d 7 : Memperbesar kamera Channel 1 s/d 7 (Solo Fullscreen View)
- Tombol 0 / ESC : Kembali ke tampilan 3x3 Grid
- Tombol F       : Layar Penuh (Fullscreen Browser)
- Klik 2x kamera : Memperbesar / mengecilkan kamera terpilih
